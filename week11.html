Caching ตอบคำถาม “reuse previous work?” ส่วน Session State ตอบ “remember this user's workflow?”

Order matters: callback ทำงานก่อน แล้วแอปจึงรันจากบนลงล่าง ดังนั้นค่าที่แสดงในรอบ rerun นั้นสะท้อนการอัปเดตแล้ว ไม่ต้องรอรอบถัดไป

Button callbacks: on_click=f vs on_click=f() ★★★

✅ ส่งฟังก์ชัน (pass the callback)

Increment ถูกคลิก → callback ถูกเรียก → count += 1 → script rerun · กด “Click ME!” แค่ rerun เฉย ๆ count ไม่เปลี่ยน

❌ เรียกฟังก์ชันทันที (call it)

count เพิ่มทุก rerun ทั้งตอนโหลดหน้าแรก (Count = 1) และตอนกดปุ่มอะไรก็ได้ แม้แต่ “Click ME!”

ลองเล่น ลำดับ callback และความต่างของ f vs f()

Input callbacks: on_change + args / kwargs

A · on_changeใช้กับ text_input, slider, selectbox, checkbox และ input widget ส่วนใหญ่
B · args / kwargsส่งค่าคงที่ให้ callback เช่น on_click=add, args=(5,) หรือ kwargs={"step": 5}
C · ค่า widget ปัจจุบันภายใน callback อ่านค่า keyed widget จาก st.session_state
