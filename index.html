ทุกสัปดาห์

ข้อสอบจำลอง

สุ่มข้อกา 15 + ข้อเขียน 15 ข้อจากคลังทุกสัปดาห์ พร้อมเฉลย สรุปคะแนนรายสัปดาห์ และจับเวลาได้

วิธีใช้เว็บนี้ให้ได้ผล

  1. อ่านทีละสัปดาห์ตามลำดับ (9 → 13) เพราะแต่ละสัปดาห์ต่อยอดจากสัปดาห์ก่อน กด “อ่านหัวข้อนี้จบ” เพื่อเก็บความคืบหน้าไว้
  2. โค้ดที่มีจุด ● ให้คลิกบรรทัดนั้นเพื่อดูคำอธิบาย หรือกด “อธิบายทุกบรรทัด” ข้อสอบมักถามว่า “ส่วนนี้ทำงานอะไร” จึงควรอ่านส่วนนี้ให้ละเอียด
  3. กล่อง “ลองเล่น” คือตัวจำลองพฤติกรรมของ Streamlit ช่วยให้เห็นภาพ rerun, cache hit/miss และ session ที่แยกกัน
  4. ทำแบบฝึกหัดท้ายบท ข้อกาจะเฉลยทันที ส่วนข้อเขียนให้ลองเขียนเองก่อน แล้วกดดูแนวคำตอบกับคำสำคัญที่ควรมี
  5. ก่อนสอบ อ่าน สรุปย่อ แล้วทำ ข้อสอบจำลอง ดูว่าสัปดาห์ไหนยังอ่อนอยู่

เทคนิคตอบข้อเขียน

คำถามทฤษฎี “X คืออะไร / ต่างกันอย่างไร”

  1. นิยาม 1 ประโยค
  2. ทำไมต้องมี (เชื่อมกับ rerun model)
  3. ตัวอย่าง หรือโค้ดสั้น ๆ
  4. ถ้าเป็นการเปรียบเทียบ ให้แยกตาม scope / purpose / lifetime

คำถามโค้ด “โค้ดนี้ทำงานอย่างไร / ได้ผลอะไร”

  1. ไล่ตามลำดับ จากบนลงล่าง เหมือน Streamlit
  2. ถามตัวเองว่า rerun แล้วบรรทัดไหนรันซ้ำ และค่าไหนรอด (cache / session_state)
  3. ดู decorator, key=, on_click= และ if ให้ดี
  4. เขียนผลลัพธ์พร้อมเหตุผล
