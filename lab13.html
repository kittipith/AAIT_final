Local คือเราทำอาหารกินเองที่บ้าน ส่วน GitHub คือสูตรอาหารที่เขียนเก็บไว้ (source code) Community Cloud คือร้านอาหารที่อ่านสูตรนั้นแล้วทำอาหารเสิร์ฟ ร้านต้องรู้ว่าใช้วัตถุดิบอะไร (requirements.txt) และกุญแจตู้เซฟ (Secrets) ที่ห้ามเขียนลงในสูตรที่คนอื่นอ่านได้

🔗 เชื่อมกับ Week 9: Local vs Deployed
ตอน Local นั้น server กับ browser อยู่เครื่องเดียวกัน (one machine, still two roles) แต่พอ Deploy แล้ว server คือเครื่องบน cloud ผู้ใช้อยู่อีกเครื่อง เชื่อมกันผ่าน network ดังนั้น path, library และ secret ต้องมีอยู่บน cloud server ไม่ใช่บนเครื่องเรา ทุกขั้นตอนใน Lab นี้มีไว้เพื่อ “ขนสิ่งที่ server ต้องใช้” ขึ้นไปให้ครบ

2 Section 1: เตรียมตัวก่อน Deploy W13★

ก่อนนำแอปขึ้น cloud ต้องเตรียมส่วนประกอบของ project ให้ครบ เพื่อให้ server สร้าง environment และรันแอปได้ถูกต้อง ใกล้เคียงกับ environment บนเครื่องเรา

สิ่งที่ต้องมีใช้ทำอะไร
GitHub account (github.com)เก็บ source code ใน repository ซึ่ง Community Cloud จะดึงโค้ดไป deploy
Streamlit Community Cloud account (share.streamlit.io)บริการที่รันแอปให้ฟรี login ด้วย GitHub หรือ Google account ได้
แอปที่รันบน Local ได้แล้วถ้า local ยังพัง ขึ้น cloud ก็พังแน่นอน ต้องทดสอบก่อนเสมอ
requirements.txtระบุ Python libraries ที่แอปต้องใช้ เช่น streamlit, pandas, scikit-learn, supabase เพื่อให้ cloud environment ติดตั้ง dependencies ก่อนเริ่มรันแอป
.streamlit/secrets.toml (เฉพาะแอปที่ต่อ Supabase)เก็บข้อมูลที่ไม่ควรเขียนไว้ใน source code เช่น URL และ Key สำหรับเชื่อมต่อ Supabase
⛔ ข้อควรระวัง (ออกสอบแน่นอน)
ห้าม Upload หรือ Commit .streamlit/secrets.toml ขึ้น GitHub เด็ดขาด เพราะ repository อาจเป็น public ใครก็อ่าน key ได้ แล้วนำไปเข้าถึง database ของเรา บน cloud ให้ใส่ค่าในช่อง Advanced settings → Secrets แทน (ดูหัวข้อ 8)

3 requirements.txt: บอก cloud ว่าต้องติดตั้งอะไร W13★★★

เครื่องของเรามี library ที่ pip install ไว้แล้ว แต่ cloud server เริ่มจาก environment ว่าง ๆ มันจะไม่รู้ว่าต้องติดตั้งอะไร ถ้าไม่มี requirements.txt จึงต้องเขียนไฟล์นี้ไว้ ในโฟลเดอร์เดียวกับ main.py

Library ไหนต้องใส่ และไหนไม่ต้องใส่?

External libraries → ต้องใส่

library ที่ติดตั้งเพิ่มด้วย pip เช่น

  • streamlit: สร้าง Web Application
  • pandas: อ่านและจัดการข้อมูล CSV
  • (Helpdesk) scikit-learn, supabase
Python Standard Library → ไม่ต้องใส่

มาพร้อม Python อยู่แล้ว เช่น datetime, hashlib, pathlib, random, json, re, time

main.py ของ Lab 13 import ทั้งหมดนี้ แต่ใช้ external library แค่ 2 ตัว

เช็กเวอร์ชันที่เครื่องเราใช้ด้วย pip show

เขียนไฟล์และ “pin” เวอร์ชัน

รูปแบบความหมายตัวอย่าง
pkgไม่ระบุเวอร์ชัน ติดตั้งเวอร์ชันล่าสุดตอน deploy (เสี่ยงที่สุด)pandas
pkg==Xต้องเป็นเวอร์ชันนี้เท่านั้นpandas==2.2.3
pkg<=Xไม่เกิน X (สิ่งที่ Lab ใช้)streamlit<=1.50.0
pkg>=Xอย่างน้อย X (ใหม่กว่าได้)supabase>=2.0
★ ทำไมต้องกำหนดเวอร์ชัน?
เพื่อลดโอกาสที่แอปบน cloud จะทำงานต่างจากเครื่อง Local เพราะถ้าไม่ล็อกไว้ cloud อาจติดตั้ง library เวอร์ชันใหม่กว่าที่เราใช้พัฒนาและทดสอบ ซึ่งอาจเปลี่ยน API หรือพฤติกรรม (เช่น parameter บางตัวเลิกใช้) ทำให้แอปพังทั้งที่โค้ดไม่ได้เปลี่ยน
ลองเล่น สร้าง requirements.txt จาก import ของ Lab 13 main.py

เลือกว่าแต่ละ import เป็น Standard library หรือ External แล้วกด “สร้างไฟล์” ระบบจะตรวจคำตอบและสร้าง requirements.txt ให้

  2. เลือก Deploy a public app from GitHub

9 Checkpoint 2 + Troubleshooting W13★★

⚠ เปิดหน้าเว็บได้ ≠ Deploy สมบูรณ์
การที่แอปเปิดหน้าเว็บได้สำเร็จ ไม่ได้หมายความว่า Deployment สมบูรณ์ ถ้าแอปเชื่อมต่อ Database ไม่ได้ หรือส่วนสำคัญของระบบทำงานไม่ได้ ต้องทดสอบ workflow หลักของ Helpdesk ให้ครบบน cloud เช่น query ตาม date/category และโหลด training data
อาการ / Errorสาเหตุที่เป็นไปได้วิธีแก้
ModuleNotFoundError: No module named 'supabase'ไม่ได้ใส่ library ใน requirements.txt (หรือไฟล์ไม่ได้อยู่ข้าง main.py)เพิ่มชื่อ package แล้ว commit ใหม่
KeyError ที่ st.secrets["supabase_url"]ไม่ได้วาง Secrets ใน Advanced settings หรือชื่อ key ไม่ตรงวางค่าจาก secrets.toml ให้ชื่อตรง supabase_url / supabase_key
FileNotFoundError หรือแอปฟ้อง “Cannot read data/…”ไม่ได้ upload โฟลเดอร์ data/ หรือใช้ path แบบ hard-code ของเครื่องเราupload data/ และใช้ Path(__file__).resolve().parent
permission denied for table ...role anon ไม่มีสิทธิ์ SELECTรัน GRANT SELECT ON TABLE ... TO anon; (Lab 12)
“Main module does not exist”Entry point / branch ผิดตั้ง Main file path = main.py, branch = main
Local ทำงานแต่บน cloud error แปลก ๆcloud ติดตั้ง library เวอร์ชันต่างจากเครื่องเรา หรือ Python version ต่างกันpin เวอร์ชันใน requirements.txt และเลือก Python version ให้ตรง
ลองเล่น เห็น error แบบนี้ ต้องไปแก้ที่ไหน?
